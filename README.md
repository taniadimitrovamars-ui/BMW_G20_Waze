# BMW G20 MGU & Waze Helper (PWA / GitHub Pages)

Помощен уеб панел за работа с **BMW G20 330i xDrive** (iDrive 7 / MGU, `idrive7-8-ssh-root`, `mgu-store`, `Waze on cluster`, BimmerCode и Sport+).

## Какво съдържа ZIP архивът
- `index.html` — цялото интерактивно приложение (чек-лист по части 0–9, златни правила, команди с копиране, Sport+ и бележки, справочник при грешки, експорт/импорт на състоянието).
- `manifest.json` — манифест за инсталация като приложение (PWA) на телефон и десктоп.
- `sw.js` — Service Worker за офлайн достъп след първо зареждане.
- `favicon.ico` — икона за табовете в браузъра.
- `icons/icon-180.png`, `icons/icon-192.png`, `icons/icon-512.png` — икони за iOS / Android / начален екран.

## Пускане през GitHub Pages
1. Разархивирай ZIP файла.
2. Създай ново хранилище в GitHub и качи съдържанието в корена на клона `main`.
3. В **Settings -> Pages** избери **Deploy from a branch** -> `main` -> `/ (root)` и запази.
4. Отвори адреса на телефон или MacBook и при нужда избери **„Добави към начален екран“**.

## Важно
- Уеб браузърът не изпълнява директно ENET/SSH команди към автомобила — същинските команди се изпълняват от MacBook през Terminal и ENET кабел.
- Не качвай в публично хранилище ключове от `data/enrollments/` или лични бекъпи.
